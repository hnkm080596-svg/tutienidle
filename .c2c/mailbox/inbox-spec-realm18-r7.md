[C2C] STATE FINDINGS · ROUND 7
High — save-compat semantics are underspecified. The spec says “no save migration unless existing normalization already handles old caps,” but increasing KD+ maxLevel from 9 to 18 changes the meaning of persisted realmLevel. A pre-change player saved at golden_core, realmLevel: 9 was previously at the realm cap/breakthrough boundary; after this mission the same save becomes only halfway through the realm. Simple range normalization/clamping does not preserve that semantic position. The spec must explicitly rule one of these behaviors: old KD+ saves retain their numeric level and intentionally lose cap status, or old 1–9 progress is migrated/remapped into the 1–18 scale, with level 9 mapping to the new cap. Without that ruling, “save-safe” behavior is ambiguous and can create a real progression regression.
Medium — getGlobalCultivationLevel / equipment-scaling semantics need a pinned invariant, not only “must still behave.” Preserving each realm's cultivation-time budget is coherent: the same total budget distributed over 18 weighted tiers gives finer progression without changing total time. But doubling KD+ minor levels also changes any system whose scaling is based on global minor-level count. If equipment or other rewards scale per getGlobalCultivationLevel, end-of-realm values may materially increase even though time budgets stay fixed. The spec should state whether end-of-realm global-level-derived scaling is intended to increase with the canonical 18-level model or whether those totals must remain equivalent to the old 9-level progression. A hard-coded-9 sweep alone does not catch semantic consumers that derive behavior from level count.
Low — KD+ realm count is internally inconsistent. The spec says “the six KD+ realm rows (golden_core…tribulation),” but that inclusive range contains seven rows: Golden Core, Nascent Soul, Soul Transformation, Void Refinement, Body Integration, Mahayana, and Tribulation. The mandated behavior says “every KD+ realm row,” so implementation intent is recoverable, but the spec should say seven to remove ambiguity.
Apart from those points, the core time-budget design is coherent: changing only the tier count while retaining each realm's authored total duration and existing weighting formula preserves total cultivation time while normalizing the canonical 18-minor-level structure.
