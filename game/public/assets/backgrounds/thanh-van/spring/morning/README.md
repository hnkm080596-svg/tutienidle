# Thanh Van — Spring Morning

Layered 2D ink-wash combat background prototype. These assets are staged only and are not mounted in `CombatScene` yet.

Canvas: `1672 × 941` (16:9)

Render order:

1. `00-sky.png` — opaque sky and sunrise base
2. `01-far-mountains.png` — distant mountains and cloud sea
3. `02-midground.png` — gate, pavilion, central mountain, and waterfall
4. `03-battle-ground.png` — perspective stone combat terrace
5. `04-foreground-left.png` — peach tree and left framing rocks
6. `05-foreground-right.png` — stone lantern and right framing rocks
7. `06-atmosphere.png` — mist and drifting peach petals

Reference files:

- `thanh-van-spring-morning-master.png` — approved flattened concept
- `preview-composite.png` — QA composite assembled from the seven layers above

Art direction: refined Chinese ink wash, restrained jade and pale peach mineral colors, early spring sunrise from the upper right, low-detail central combat floor, no baked UI or battle grid.
