# Thanh Vân modular backgrounds

Canvas: `1672 × 941`.

The four season folders contain six transparent scenery layers each:

1. `01-far-mountains.png`
2. `02-midground.png`
3. `03-battle-ground.png`
4. `04-foreground-left.png`
5. `05-foreground-right.png`
6. `06-atmosphere.png`

The four time folders contain an opaque `00-sky.png`. Combining one time sky with one season stack yields all sixteen Thanh Vân backgrounds. The `previews` folder contains flattened QA composites only; runtime should load the modular source layers.

Suggested runtime grading after the layers are composed:

- morning: warm ivory light, no additional darkening
- noon: about `+4%` luminance and slightly reduced saturation
- evening: restrained warm cinnabar wash around `14%`
- night: charcoal-indigo wash around `42%`, luminance around `68%`

No layer contains a battle grid, UI, character, or VFX.
