# Learned Defects

This ledger records evidence-backed defects that should shape future TutienIdle adversarial QA. It starts empty: do not fabricate rows from hypothetical risks, static concerns, or unverified failures.

## Entry Criteria

Only `Confirmed` defects enter this ledger, and a row may be appended only after the report contains the supporting intended failing reproduction test or direct runtime evidence. Record the regression-test path when one exists; otherwise state the evidence-backed reason no regression test is available.
